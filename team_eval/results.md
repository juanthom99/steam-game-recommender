# Team comparison: our models on the shared validation holdouts

Built with `team_eval/` (validation players only; the test set is untouched). Scored by `team_eval/evaluate.py`, the same
script teammates use, so any model scored with it is directly comparable. Run date: 2026-11-04.

Models: **ease** (our candidate), **ease_safe** (EASE plus a flag-aware re-rank, `team_eval/rerank.py`),
**hybrid_ease** (EASE plus description embeddings), **mostpopular** (baseline).

**Summary**
- EASE beats MostPopular on every accuracy and playtime metric, on all three holdouts (80/20, 75/25, 50/50).
  80/20: NDCG@10 0.276 vs 0.038; HitRate@10 (any hidden game) 0.75 vs 0.33; picks within 2x of the player's average playtime 33% vs 20%.
- EASE-safe cuts flagged picks from 32% to 21% (short games 8% to 3%, two or more flags 4.5% to 1.2%) and regret from 19% to 17%,
  for about 2% less NDCG@10 (0.270 vs 0.276) and no change in HitRate@10 (any).
  Setting chosen on 75/25 by a rule fixed beforehand (lowest flag share with NDCG@10 >= 98% of EASE): a = 0.5 (like quit), b = 1 (short), c = 10 (negative).
  80/20 and 50/50 confirm it, but they share players with 75/25, so they are not fully independent checks.
- Trade-off: stronger penalties lower flags further (below MostPopular's 18% at a = 1, b = 1 for 3% less NDCG; 2.6% at a = 4, b = 2 for 17% less).
  The full grid is below; pick the operating point as a product decision.
- Hybrid-EASE vs EASE: +0.001 NDCG@10 on 80/20 and 75/25, none on 50/50. Its value is new games EASE cannot score.
- Regret stays above MostPopular (17% vs 10%); the earlier diagnosis attributes this mostly to MostPopular picking only the top games.
- Check: 80/20 reproduces Run 2's validation numbers (MostPopular 0.0379, Hybrid-EASE 0.2773 vs 0.2771 in tuning).
